# HURO VISUAL (Minecraft Java 1.21.4 + Fabric)

Фиолетовый визуальный клиент-мод + лаунчер с кнопкой «ИГРАТЬ».

## Как получить готовые файлы (без программирования)

1. Зайдите на github.com, создайте аккаунт (бесплатно) и нажмите **New repository** (название любое, например `huro`).
2. Нажмите **uploading an existing file**, перетащите ВСЁ содержимое этой папки (включая скрытую папку `.github`) и нажмите **Commit changes**.
3. Откройте вкладку **Actions** → **Build HURO VISUAL** → **Run workflow**. Подождите 5–10 минут.
4. Внутри завершённого запуска скачайте:
   - **HURO-Launcher-installer** — установщик `.exe` лаунчера (Java внутри, ничего ставить не нужно);
   - **HURO-Launcher-jar** — тот же лаунчер как `.jar` (нужна Java 17+);
   - **HURO-VISUAL-mod** — отдельный файл мода (он уже встроен в лаунчер).

Если сборка упала красным — откройте её, скопируйте текст ошибки и пришлите мне, я исправлю.

## Как пользоваться

1. Один раз откройте официальный Minecraft Launcher (Mojang), чтобы он создал папку игры.
2. Запустите **HURO Launcher** → нажмите **ИГРАТЬ**. Он поставит Fabric 1.21.4, Fabric API и мод, затем откроет лаунчер Mojang.
3. В лаунчере Mojang выберите профиль **fabric-loader-1.21.4** и нажмите **Играть** (нужна лицензия Minecraft).
4. В игре нажмите **Right Shift** — откроется меню HURO VISUAL.

## Меню (Right Shift)

- **Visuals** — частицы и вспышка при ударе, Hit Sound, рывок камеры, Fullbright, время и погода (только у вас на экране), свой прицел.
- **HUD** — FPS, CPS, Ping, координаты, Keystrokes, броня, зелья, комбо.
- **Ultimate** — эффект убийства, пресеты, профили настроек.
- **Optimization** — пресет FPS-буст, дальность прорисовки, лимит FPS, VSync, облака, тени, частицы.
- **Friends** — список друзей (без эффектов ударов по ним, подсветка рядом).
- **Markers** — метки на экране с расстоянием; клавиша **J** ставит метку на месте.

Настройки сохраняются в `.minecraft/config/huro_visual/`.

Мод работает только на клиенте и ничего не меняет на сервере (fullbright, время и погода видны только вам).
